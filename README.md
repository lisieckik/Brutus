This is repository for BRUTUS. It is a tool used for SIMBA cosmological simulation. 
It is a GUI for forking with galaxy catalogue (Group catalogue). 
It allows also for tracking individual galaxies in time.

Papers for which BRUTUS was used:
Lorenzon+25a
Lisiecki+26a
Lisiecki+26b
Matera+ in prep.

If you use it, try to cite some of the above.
